# Psalm First pictures

Full-size encyclopedia pictures for the Psalm First iPhone app. The app fetches a picture from `v1/` the first time a reader opens its entry and keeps it on the phone.

- Every picture is public domain or openly licensed (CC0, CC BY, CC BY-SA). The source, author and licence of each one are in `LICENSES.json`, and in the app under Settings, Credits.
- Do not rename, delete or make this repository private: the app points at it by name.
- Files in `v1/` never change once published. New or replaced pictures go in a new folder (`v2/`), and the app is pointed at it.
